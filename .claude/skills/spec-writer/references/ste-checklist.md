# ASD-STE100 checklist for specs

Use this list when the house rules ask for Simplified Technical English.

- Write short sentences: 20 words maximum in procedures, 25 in descriptions.
- Write one instruction in each sentence.
- Use the active voice. "The ETL discards the row", not "The row is discarded".
- Use the imperative in instructions. "Run the ETL", not "You should run the ETL".
- Use one word for one meaning. If you call it a "plant", do not also call it a "station" or a "facility".
- Use simple verb tenses: present, simple past, simple future.
- Do not use "-ing" forms as nouns or as the start of a clause where a simple verb is possible.
- Do not use phrasal verbs when a single verb exists ("remove", not "take out").
- Put technical names (code identifiers, file names, column names) in backticks and keep them exactly as they are in the source.
- Use tables and lists instead of long paragraphs.
